# EV3 우주선 사운드 (테스트 버전)

기아 EV3 + 안드로이드 오토(유선)에서 **가상 주행음이 어떻게 들리는지**와 **소리 반응 지연이 얼마나 되는지**를 확인하기 위한 개인용 테스트 앱입니다.

## 할 수 있는 것

- 브라우저 프로토타입과 같은 우주선 사운드(코어 험, 터빈 휘슬, 에너지 노이즈, 하모닉 패드, 회생제동 반짝임, 부팅/종료음, 터널 울림)를 폰에서 실시간 합성
- **시뮬레이션 모드**: 폰 화면의 가속/회생 버튼이나 데모 주행으로 차가 서 있어도 소리 확인
- **실제 주행 모드**: GPS 속도 + 폰 가속도 센서를 섞어서 속도·가속을 추정해 소리에 반영
- **지연 측정**: 차 스피커로 '삑' 소리를 내고 폰 마이크로 다시 들어서 실제 지연(ms)을 측정
- **갱신 주기 측정**: GPS, 안드로이드 오토 차량 속도, 가속도 센서가 초당 몇 번 들어오는지 표시
- **주행 기록**: 위 값들을 CSV로 저장하고 공유

## 설치

### 방법 A: GitHub에서 자동 빌드 (PC에 개발 도구 설치 없이)

1. 이 폴더 전체를 GitHub 저장소에 올리면 `.github/workflows/build.yml`이 자동으로 APK를 빌드합니다.
2. 저장소의 **Actions** 탭 → 최신 실행(초록 체크) → 맨 아래 **Artifacts**의 `EV3SpaceSound-apk`를 받습니다 (zip 안에 APK).
3. 폰에서 APK를 열어 설치합니다. 처음에는 "알 수 없는 앱 설치" 허용이 필요합니다.
4. 서명 키(`app/debug.keystore`)가 고정되어 있어서, 새로 빌드한 APK는 기존 앱을 지우지 않고 덮어써서 업데이트됩니다. 개인 테스트용 키이니 앱을 배포하지는 마세요.

### 방법 B: Android Studio

1. Android Studio(최신 버전)에서 이 폴더를 **Open** 합니다. Gradle 동기화가 끝날 때까지 기다리세요. 버전 업그레이드를 권하면 받아들여도 됩니다.
2. 폰을 USB로 PC에 연결하고(개발자 옵션 → USB 디버깅 켜기) **Run ▶** 으로 설치합니다.

### 공통: 안드로이드 오토 설정

1. 안드로이드 오토에서 직접 설치한 앱이 보이게 설정합니다.
   - 폰 설정에서 안드로이드 오토 설정 화면을 엽니다.
   - 맨 아래 **버전** 항목을 10번 정도 눌러 개발자 모드를 켭니다.
   - 오른쪽 위 메뉴 → **개발자 설정** → **알 수 없는 출처** 켜기
2. 폰에서 앱을 처음 열 때 **위치, 마이크, 알림** 권한을 허용합니다.

## 테스트 순서 (추천)

**1단계: 집에서 소리 확인 (차 없이)**
1. 앱에서 **서비스 시작** → **사운드 켜기** (부팅음이 납니다)
2. 입력이 **시뮬레이션**인지 확인하고 **데모 주행** 또는 가속/회생 버튼으로 소리를 들어봅니다.

**2단계: 차에 유선 연결 후 지연 측정 (주차 상태)**
1. 차에 타기 전에 폰에서 **서비스 시작**을 먼저 눌러두세요. (안드로이드 오토 화면에서 서비스를 켜는 건 폰 정책상 막힐 수 있습니다.)
2. USB로 차에 연결 → 차 화면 앱 목록에서 **EV3 우주선 사운드** 실행
3. 음악을 끄고, 차 안을 조용히 하고, 폰은 평소 거치 위치에 둡니다. 볼륨은 중간 이상.
4. 차 화면이나 폰에서 **지연 측정**을 누르면 '삑' 소리가 7번 나고 결과가 표시됩니다.
5. 결과는 `latency_results.csv`에도 쌓입니다. 가능하면 무선 연결로도 한 번 측정해서 비교해 보세요.

**3단계: 실제 주행**
1. 폰을 거치대에 **단단히 고정**합니다. (움직이면 가속도 방향 학습이 틀어집니다)
2. 입력을 **실제 주행 (GPS+센서)** 로 바꾸고 **기록 시작**
3. 직선 도로에서 가속과 감속을 몇 번 하면 "보정 완료"가 뜹니다. 그 전까지는 GPS 값만 써서 반응이 느립니다.
4. 주행 후 **기록 중지** → **최근 기록 공유**로 CSV를 받아보면 GPS/차량/추정 속도를 비교할 수 있어요.

> 운전 중에는 폰이나 차 화면을 조작하지 마세요. 설정은 출발 전에 해두세요.

## 화면에 보이는 값

| 항목 | 의미 |
|---|---|
| 모드 | IDLE, BOOST, WARP, CRUISE, REGEN 등 현재 사운드 상태 |
| GPS / 차량 | 각 소스의 속도, **갱신 Hz**, 마지막 수신 시각 |
| 가속센서 | 가속도 센서 갱신 Hz와 방향 학습 상태 |
| 버퍼 | 앱 오디오 버퍼 크기. 언더런(끊김)이 생기면 자동으로 늘어납니다 |
| 지연 | 측정 결과 중앙값 (최소·최대, 성공 횟수, 출력 경로) |

## 지연 측정 결과 보는 법

- 측정값은 "앱이 소리를 내보낸 순간 → 차 스피커에서 나와 폰 마이크에 들린 순간"입니다. 앱 버퍼, 안드로이드 오토 전송, 차량 오디오 처리가 모두 포함됩니다.
- 대략 **100ms 이하**면 거의 즉각적으로 느껴지고, **200~300ms**부터는 밟는 순간 늦게 따라오는 느낌이 납니다. 사람마다 차이가 있으니 숫자와 체감을 같이 비교해 보세요.
- 감지 실패가 나오면 볼륨을 올리거나 폰을 스피커 쪽으로 옮기고 다시 해보세요.

## 설정

- **정속**: 고속 정속 4초 이상일 때 볼륨 (유지 55% / 거의 무음 15% / 무음)
- **터널**: 자동은 실제 주행에서 GPS가 3초 이상 끊기고 20km/h 이상일 때 울림 효과를 켭니다
- **배터리 부족 연출**: 자동은 안드로이드 오토에서 받은 배터리가 20% 미만일 때

## 알려진 한계

- 이 프로젝트는 빌드 도구 없이 작성되어 **아직 한 번도 컴파일되지 않았습니다.** 빌드 오류가 나면 오류 메시지를 그대로 알려주시면 고쳐 드릴게요.
- EV3가 안드로이드 오토로 차량 속도·배터리 값을 주는지는 차마다 다릅니다. "차량" 줄이 계속 비어 있으면 값이 안 들어오는 겁니다.
- 음악과 동시에 재생되도록 오디오 포커스를 요청하지 않습니다. 음악과 섞였을 때 차에서 어떻게 들리는지도 같이 확인해 보세요.
- 개인 테스트용이라 플레이스토어 배포 기준(카테고리, 품질 가이드)은 고려하지 않았습니다.

```
app/src/main/java/com/ev3/spacesound/
  audio/SynthEngine.kt     사운드 합성 (저지연 AudioTrack)
  audio/Dsp.kt             필터, 오실레이터, 리버브
  motion/MotionTracker.kt  GPS + 가속도 센서 융합
  DriveController.kt       주행 상태 → 사운드 파라미터, 시뮬레이터, 데모
  LatencyTester.kt         클릭음 지연 측정
  DataLogger.kt            CSV 기록
  EngineService.kt         포그라운드 서비스
  MainActivity.kt          폰 화면
  car/                     안드로이드 오토 화면과 차량 데이터
```
